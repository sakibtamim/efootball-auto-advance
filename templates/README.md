# Template Images

Place your small cropped PNG buttons in this folder.

Recommended templates to capture from eFootball:
1. `continue.png` - The "Continue" prompt or bottom-right action button.
2. `next.png` - The "Next", "To Next Match", or "Proceed" button.
3. `skip.png` - The "Skip" prompt during cutscenes, intro, or halftime.
4. `advance_a.png` - The controller "(A) Advance" icon/prompt.

### Tips for Best Matching
- Crop tightly around the button icon or text with minimal variable background.
- Keep the format as `.png` (lossless).
- Use `python grab_template.py` from the root folder to quickly capture screens while the game is running.
